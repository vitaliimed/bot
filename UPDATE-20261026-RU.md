# Обновление очереди от 26 октября 2026

В releases/2026-10-26/source сохранён полный подготовленный исходный код v2 с восстановлением очереди. Эта база не включает неизвестные локальные изменения Haimaker/peak50 на вашем сервере. Не копируйте её поверх рабочего проекта без сравнения.

В releases/2026-10-26/recovery находится дополнение для текущего серверного проекта: восстановление зависших материалов, повторная проверка редактором, автоматическая публикация готовой очереди через dispatch и команда /repair.

Основные файлы старой версии в корне репозитория сохранены. Используйте эту команду, а не старый upgrade-all.sh из корня:

```bash
(
set -e
UPDATE_DIR=$(mktemp -d "$HOME/bot-update-XXXXXXXX")
git clone --depth 1 https://github.com/vitaliimed/bot.git "$UPDATE_DIR"
bash "$UPDATE_DIR/scripts/update-recovery.sh" "$HOME/projects/bot"
)
```

Команда сохраняет текущие серверные доработки и настройки, делает резервную копию изменяемых файлов, разворачивает кандидата Cloud Run без трафика, проверяет версию и диагностику очередей и только затем направляет на него весь трафик. Отдельно запускать Python в Cloud Shell не нужно. В конце будет показана команда отката.

После обновления: откройте @suominews_bot, выберите «Новости», отправьте /repair и подтвердите восстановление очереди. Повторите для событий при необходимости. Автопубликация и ограничения канала сохраняются. Расписания Scheduler не меняются; диагностика выводит их состояние. Для массовой публикации используется существующее меню очереди.

Предыдущая локальная проверка: 165 тестов прошли на подготовленной базе и модуле восстановления. Внешние API заменены заглушками. Факт публикации на действующем сервере требует проверки после установки. При ошибке пришлите вывод; не запускайте старый деплой и не удаляйте базу данных.
