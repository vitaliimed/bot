# Версия для начала работы — 25 октября 2026

Это руководство актуальнее предыдущих UPDATE-MASS-RU и UPLOAD-AND-RUN-RU. Git не используется.

## Ошибки на ваших скриншотах

Ранее общий обработчик выводил «таймаут или недоступность провайдера» для любого исключения без HTTP-кода, в том числе BudgetBlocked. Поэтому скриншот не доказывает таймаут Cloudflare, Gemini, OpenAI или DeepSeek.

Исправлено:
- режим off: сообщение «Без ИИ, запрос не выполнялся»;
- free запрещает модель: объяснение режима расходов до запроса;
- нет Cloudflare Account ID: отдельная инструкция (Account ID не API-токен);
- квоты приложения: отдельное объяснение;
- 401/403: ключ / права;
- 429: баланс, квота либо частота;
- 400/404/422: модель / формат запроса;
- реальный таймаут: время ожидания;
- неверный JSON: формат ответа модели;
- отказ Secret Manager/Firestore: права сервисного аккаунта.

Сохраняется последняя проверка модели. Полные ключи, тела ответов и URL с секретами не выводятся. Проверка заблокированной модели не делает запрос и не включает искусственную паузу провайдера.

## Что новое

1. Проверка повторов перед отправкой не только по URL: точное совпадение достаточно длинного нормализованного заголовка или исходного текста блокируется транзакционно в Firestore. Срок по умолчанию 168 часов, отдельно для каждого канала. Разные даты события считаются отдельно. Короткие общие заголовки не блокируют разные новости. Старые опубликованные записи включаются в индекс миграцией. Сходство заголовков при сборе также сохраняется. Это не семантическое доказательство уникальности любых переводов.
2. Отдельный обработчик подтверждённых публикаций каждые 2 минуты. По умолчанию 3 за запуск, настройка «Массовых отправок за запуск» 1–10. Без сбора RSS и текстовых ИИ. При активном сборщике ждёт освобождения канала. Ошибку неопределённой доставки нельзя автоматически повторять.
3. «⚡ Быстрые новости» — подтверждаемый профиль: автопубликация, до 60 в день, интервал 5 минут, до 20 подготовок за сбор. Текст оригинала, ноль запросов к ИИ, фото источника или локальный шаблон. Фильтры тем/регионов и часы работы сохраняются. Сомнительные материалы продолжают ждать ручной проверки. Профиль не переводит иностранные новости на украинский.
4. «Приоритетные слова» поднимают подходящие новости в очереди. Например: транспорт, HSL, Helsinki, житло, робота. Приоритет не отменяет фильтры и проверку повторов.
5. В настройках текста — шаблоны заголовка и основной части: «📰 {title}», «Коротко: {body}». Факты берутся из карточки; выражения, атрибуты и исполняемый код запрещены. Обязательные подписи, ссылки и обозначение ИИ-изображения остаются под контролем форматтера. Для двуязычной основной части сохраняется специальный двухъязычный формат.
6. Ручной экспорт истории в JSONL через scripts/backup-history.py. Сохраняет публикации, очередь, журнал доставок, настройки и метаданные. API-ключи из Secret Manager не экспортируются. Незавершённая копия имеет complete=false.
7. Исправлено устаревшее предупреждение «нужно изображение/ключ»: резервная картинка создаётся локально. Прошедшее событие нельзя отправить как предстоящее даже через новостной канал.

## Обновление

Загрузите finland-news-bot-ready-20261025.zip в Cloud Shell. Блок ищет его в домашней папке и ~/projects/bot.

```bash
(
set -e
ARCHIVE="$HOME/finland-news-bot-ready-20261025.zip"
if [ ! -f "$ARCHIVE" ]; then
  ARCHIVE="$HOME/projects/bot/finland-news-bot-ready-20261025.zip"
fi
if [ ! -f "$ARCHIVE" ]; then
  echo 'Загрузите finland-news-bot-ready-20261025.zip в Cloud Shell.'
  exit 1
fi
UPDATE_DIR=$(mktemp -d "$HOME/finland-bot-ready-XXXXXXXX")
unzip -q "$ARCHIVE" -d "$UPDATE_DIR"
cd "$UPDATE_DIR/finland-news-bot-v2"
PROJECT_ID=winged-ratio-377512 \
REGION=europe-north1 \
EVENTS_CHANNEL_ID=@eventhsl \
COLLECT_SCHEDULE='*/5 * * * *' \
bash scripts/upgrade-all.sh
bash scripts/diagnose.sh
)
```

Новости будут проверяться Scheduler каждые 5 минут, события сохраняют прежнее расписание. У источника также есть собственный интервал; профиль быстрых новостей выставляет RSS выбранного канала 5 минут. Изменение Scheduler само по себе не включает автопубликацию и не отключает ИИ. Настройки остальных каналов сохраняются.

Добавится задание finland-news-dispatch. Оно отправляет только уже подтверждённые задания, включая ранее запланированные. Отмените ненужные старые задания до обновления. Дополнительные запуски Cloud Run, Scheduler и чтения Firestore учитываются Google Cloud: ноль расходов ИИ не означает гарантированно нулевой счёт облака.

## Начало использования

1. /start → выберите Новости. Проверьте /diagnose.
2. Если подходит публикация на языке оригинала: «⚡ Быстрые новости» → прочитайте параметры → подтвердите. Для украинского перевода иностранного материала нужен работающий переводчик или ручная редактура; не выдавайте оригинал за перевод.
3. Настройки → Темы и фильтры: категории, исключения, регион, приоритетные слова. Настройки → Расписание: частота, суточный лимит, количество обработки и массовых отправок.
4. «Собрать» запускает сбор раньше расписания.
5. Для новости прямо сейчас: «Неопубликованные» → «Выбрать канал» → проверьте точное превью → подтвердите. Отправка этой одной карточки идёт в рамках действия сразу, без ожидания очередного Scheduler.
6. Для большой группы: /mass → 10/25/50/100 → канал → список/предупреждения/превью → подтверждение. По умолчанию 100 заданий займут около 68 минут, если нет занятого коллектора, ошибок и ограничений Telegram. При настройке 10 за запуск — примерно 20 минут. Это расчёт по расписанию, не гарантия доставки.
7. /mass → Статус / отмена: следите за ошибками, отменяйте ещё не начатые задания. Повторное нажатие подтверждения не создаёт повторную группу.
8. Начните с одного проверенного поста в каждом канале, затем небольшой группы. Проверьте изображения, подпись, текст и отсутствие дублей.

## ИИ и Cloudflare

«Без ИИ» — полностью рабочий режим с нулём API-запросов. «Бесплатный режим» разрешает только явно предусмотренные бесплатные маршруты; подключённый ключ OpenAI/DeepSeek сам по себе не делает API бесплатным.

Cloudflare: ИИ → Cloudflare → добавить ключ; Настройки → Бюджет → cloudflare_account_id. Укажите Account ID своего аккаунта. Подтверждайте cloudflare_free_account только после проверки тарифа в кабинете. Затем выберите доступную текстовую модель и нажмите тест. Отдельный тест текста не проверяет генерацию картинок.

Модели не были заменены наугад: официальные страницы подтверждают gemini-3.5-flash-lite и gpt-image-2.5-flare. Это подтверждает ID модели, но не ваш баланс, ключ или персональный доступ.
- https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite
- https://developers.openai.com/api/reference/resources/images/methods/generate

## Резерв и откат

Перед развёртыванием upgrade-all.sh автоматически сохранит настройки и предыдущий трафик. Путь к rollback.sh будет в выводе.

Полная прикладная копия истории, если нужна, выполняется вручную из распакованного проекта:

```bash
python3 scripts/backup-history.py --project winged-ratio-377512
```

Файлы приватные, содержат тексты постов и изображения из Firestore. Скачайте папку с complete=true из Cloud Shell. Это последовательный прикладной экспорт, не атомарный снимок всей БД; во время записи данные могут меняться. Автоматического восстановления поверх рабочей базы нет: сначала проверка копии и отдельный план восстановления. Чтения тарифицируются согласно вашему GCP-плану.

Перед откатом приостановите новый обработчик, чтобы старая ревизия не получала неизвестный endpoint:

```bash
gcloud scheduler jobs pause finland-news-dispatch \
  --project=winged-ratio-377512 --location=europe-west1
```

Затем выполните rollback.sh, указанный обновлением. Если требуется остановить и обычную автопубликацию — отключите её в меню каждого канала. Откат кода не удаляет опубликованные сообщения и не отменяет задания Firestore.

## Что пока нельзя подтвердить

Новый пакет проверен локально, но не развёрнут нами в вашем облаке. Реальные доставки, действительность ключей, квоты, права IAM и все внешние источники требуют диагностики после установки. Закрытые Facebook Events не читаются; отдельный Ticketmaster-коннектор без ключа не подключён. Автоматический платный переход отсутствует. Денежный потолок платных провайдеров требует их собственных ограничений; в боте есть лимиты попыток. Полное соответствие всех внешних интеграций не заявляется.
