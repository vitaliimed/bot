# Обновление News & Events Bot 2.0

Подготовлены режим без ИИ, бесплатный режим с запретом перехода к платным моделям, локальные изображения Pillow, постоянное меню, ключи Secret Manager, независимые каналы, импорт анонсов, ручная публикация с выбором канала, планирование, групповые действия и диагностика.

## Обновление

```bash
(
set -e
cd "$HOME/projects/bot"
git pull --ff-only
PROJECT_ID=winged-ratio-377512 REGION=europe-north1 EVENTS_CHANNEL_ID=@eventhsl bash scripts/upgrade-all.sh
bash scripts/diagnose.sh
)
```

Скрипт сохраняет резервную копию настроек и конфигурации сервиса в ~/bot-backups, проверяет новую ревизию без перевода трафика и без публикаций, затем переводит трафик. Команда отката выводится в терминале и сохраняется в rollback.sh рядом с резервной копией. История материалов остаётся в Firestore.

## Без ИИ

Откройте /start → «Без ИИ» в каждом нужном канале. Исходный текст публикуется на языке оригинала, изображение берётся из разрешённого источника или создаётся локально. Автопубликация включается отдельно.

«Максимально бесплатно» сохраняет украинский текст без ИИ, а иностранный пытается перевести через разрешённый бесплатный API. При недоступности перевода оригинал остаётся для ручной проверки. Платные модели автоматически не подключаются. Cloudflare допускается в бесплатном режиме только после подтверждения владельцем тарифа Workers Free. Hugging Face не считается гарантированно бесплатным.

## Управление

- /ai: провайдер → добавить ключ → проверить. Ключами управляет владелец основного канала. Отключение провайдера относится к выбранному каналу; удаление подключения — ко всему боту. Отзыв ключа в кабинете провайдера выполняется отдельно.
- /unpublished: карточка → выбрать канал → проверить превью → подтвердить или запланировать.
- «В группу»: выбрать до 10 карточек и подтвердить групповое действие.
- /channels: добавить канал; бот и администратор должны иметь права публикации. Архивирование сохраняет историю.
- /import: ссылка, текст или пересланный анонс. Закрытые страницы Facebook не читаются.
- /diagnose: причины задержек, очереди, источники и режим ИИ.
- /usage: попытки запросов, кеш, локальная обработка; неизвестная стоимость не считается нулевой.
- /backup: резервная копия настроек в Firestore с возможностью восстановления.

## Проверено и ограничения

Автоматические проверки: 129 тестов успешно в среде разработки; реальные ключи и публикации не использовались. Повторная проверка доступности: 27 новостных RSS и 2 RSS организаций ответили. Это количество лент, а не независимых редакций.

Для событий добавлены календарь Pro Ukraina, Tiketti, библиотечные темы и культурные центры через Linked Events. Facebook, Fienta, Lippu.fi и Telegram доступны через ручной импорт. Полное покрытие всех календарей, Ticketmaster и закрытых сообществ не заявляется.

Фактическая причина остановки действующего канала пока не подтверждена: требуется вывод диагностики из авторизованной Cloud Shell. Обнаружены и исправлены ограничения старого сборщика: проверка только начала готовой очереди и расход времени обработки на источники до подготовки накопленных материалов.

Планирование выполняется при первом запуске Scheduler после заданного времени. Дополнительные каналы обрабатываются по очереди существующими заданиями. Лимиты ИИ ограничивают количество попыток; это не гарантированный денежный потолок платного API. Для денежного ограничения используйте лимиты кабинета провайдера. Google Cloud может иметь собственные расходы.

Успешный запуск Cloud Run, текущие права API и реальные публикации должны быть проверены после выполнения команды обновления. До этого версия не считается проверенной в эксплуатации.

## Создать свой пост с нуля, без подключённых ИИ

Нажмите «✍️ Создать пост» или отправьте /newpost. Следующим сообщением пришлите собственный текст: первая строка станет заголовком. Можно прислать фото с подписью либо позже заменить фото в карточке. Если изображения нет, при публикации создаётся локальный шаблон. Откройте «Выбрать канал», проверьте превью и подтвердите отправку. Для этого не нужны API-ключи, переводчик или генератор ИИ. Модель не вызывается даже при пустом списке подключений.
