# Установка из архива без Git

## Обновить существующий сервис

Загрузите finland-news-bot-v2-20261025.zip в домашнюю папку Cloud Shell через Upload file. Затем выполните:

```bash
(
set -e
cd "$HOME"
unzip -q finland-news-bot-v2-20261025.zip
cd finland-news-bot-v2
PROJECT_ID=winged-ratio-377512 \
REGION=europe-north1 \
EVENTS_CHANNEL_ID=@eventhsl \
bash scripts/upgrade-all.sh
bash scripts/diagnose.sh
)
```

Старую папку ~/projects/bot команда не меняет. Новая версия собирается из распакованного архива, без Git. Повторно не распаковывайте архив поверх уже изменённой папки: используйте отдельную папку или сохраните предыдущую.

Скрипт сначала проверяет текущий сервис, Telegram и права, сохраняет резервную копию настроек и конфигурации в ~/bot-backups, развёртывает кандидата без трафика, проверяет health и создание изображения без ИИ и публикаций. Только затем переводит трафик на новую ревизию. После этого выполняются совместимая миграция каталога и проверки Scheduler/webhook. Существующая история не удаляется. При ошибке не повторяйте обновление вслепую: сохраните вывод диагностики.

## Первый запуск

1. Откройте @suominews_bot, отправьте /start.
2. Выберите Новости или События. У каждого канала свои настройки и переключатель авто.
3. Для полного отказа от ИИ нажмите «Без ИИ». Тогда текст остаётся на языке оригинала. Для украинских публикаций пишите по-украински или используйте украинский источник.
4. «Создать пост» → собственный текст либо фото с подписью → «Выбрать канал» → превью → подтверждение. API-ключи не нужны.
5. «Неопубликованные» показывает готовые, отфильтрованные, устаревшие, отклонённые, запланированные и ошибочные материалы. В карточке доступны статус, заголовок, текст, фото, повтор обработки и отправка.
6. «В группу» добавляет до десяти материалов. Публикация выбранных и отклонение требуют подтверждения. Отклонение сохраняет материал; восстановление возможно через повтор обработки или ручную правку.
7. После ручной проверки включите автопубликацию отдельно в нужном канале. Обновление само не снимает ваши фильтры.

## Бесплатный режим и ИИ

«Максимально бесплатно» допускает OpenRouter openrouter/free и модели :free. Cloudflare разрешается после указания Account ID и явного подтверждения владельцем тарифа Workers Free. Другие провайдеры в этом режиме не вызываются. Наличие бесплатных пробных кредитов не означает неограниченный бесплатный API.

ИИ → провайдер → добавить ключ → проверить. Ключи в Secret Manager, сообщения с ключами бот пытается удалить. Общие ключи меняет владелец основного канала. Удаление подключения не отзывает ключ в кабинете провайдера.

Порядок перевода translation_order настраивается отдельно; пустой список использует общий ai_order. В расширенных настройках ИИ доступны основная и резервная текстовые модели каждого провайдера. Проверяющий и генераторы картинок выбираются отдельно. Оформление HTML и создание графического шаблона выполняются локально.

Дневные и месячные квоты считаются по попыткам в UTC, включая неудачные. Режим paid является явным разрешением платных API. Лимиты количества запросов не заменяют денежные лимиты провайдера. Фактическая стоимость показывается только если API её сообщает; иначе она неизвестна. Расходы Google Cloud отдельны.

## Источники и изображения

27 новостных RSS были доступны при проверке 24.10.2026, плюс 2 RSS организаций. Тематические ленты одной редакции не являются независимыми СМИ.

События: Helsinki/Espoo/Vantaa через Linked Events, библиотечные темы Helmet в общем API, Pro Ukraina (RSS и календарь), Ukrainians.fi, Tiketti, тематические выборки Stoa/Vuotalo/Malmitalo/Kanneltalo/Annantalo/Caisa. Выборки организаторов могут пересекаться с городским API; дубликаты учитываются.

Facebook, Lippu.fi, Fienta и анонсы Telegram — ручной импорт конкретной ссылки/текста. Закрытые группы не читаются; защиты не обходятся. По конкуренту нельзя подтвердить полный набор первоисточников из недоступной публичной ленты. Автоматического копирования его публикаций нет.

Фото используйте с разрешением владельца: переключатель sourceimages задаёт допуск источника. Без фото создаётся локальная карточка. В настройках изображений можно выбрать стиль и загрузить логотип. ИИ-картинки помечаются как иллюстрации. Прошедшие и отменённые события нельзя отправить как предстоящие.

## Диагностика, тесты и откат

/diagnose показывает очереди и причины блокировки; /failed — сохранённые ошибки; /usage — запросы и локальную обработку. Автоматические уведомления об ошибках объединяются по типу и каналу. Независимый finland-news-watchdog проверяет задержки сбора, рост очереди, отсутствие публикаций, лимит ИИ и backlog webhook каждые 30 минут. Полная недоступность Cloud Run или всего Scheduler требует внешнего мониторинга Google Cloud: внутренняя проверка при таком сбое не запустится.

```bash
bash scripts/diagnose.sh
```

Перед обновлением backup-state.py читает реальные настройки/статусы из Firestore. Это необходимо для установления фактической причины остановки новостей. Ранее обнаруженные ограничения кода — только проверка начала готовой очереди и расход бюджета времени на источники до обработки старой очереди — исправлены, но не доказывают причину конкретного серверного сбоя.

Копии настроек создаются также через /backup. Они не заменяют полный резервный экспорт Firestore с историей. История остаётся в действующей базе. Команда отката трафика сохраняется в ~/bot-backups/ДАТА/rollback.sh и выводится при обновлении. Откат старого кода может вернуть использование старых ключей из окружения; отзыв ключей выполняйте у провайдера.

Тестовый режим: DRY_RUN=1 запрещает отправку в каналы через публикатор. Автоматические тесты используют подставные Telegram/API и не публикуют реальные посты.

Для самостоятельного запуска тестов:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
```

## Что необходимо подтвердить после загрузки

Успешную сборку, права Secret Manager/Firestore, Scheduler, webhook и одну проверенную реальную публикацию в каждом нужном канале. До получения этих результатов эксплуатационная готовность не подтверждена.

Ограничения полной спецификации: нет гарантированного покрытия всех сайтов; Ticketmaster требует отдельного подключения с доступом к API; внешнее наблюдение за остановкой Scheduler и точные счета Google Cloud не заменены внутренней статистикой. Дедупликация по сходству консервативная, без автоматического смешивания фактов разных статей. Индивидуальный произвольный HTML-конструктор шаблонов не реализован: доступны готовая структура, язык, подпись, категории, стили карточек и логотип. Эти ограничения нельзя обозначать как завершённую полную реализацию ТЗ.
