# Проверка всего технического задания

Этот файл отделяет сделанное в коде от проверок, требующих вашего рабочего аккаунта. Новая версия не объявляется полностью проверенной в эксплуатации до реальных тестов после установки.

| Раздел | Состояние |
|---|---|
| Аудит инфраструктуры | Из вашего журнала подтверждены Cloud Run, два Scheduler, webhook, права каналов, версия и состояние очередей. Текущий доступ к облаку из разработки отсутствует. |
| Постоянное меню | Reply-клавиатура, динамические inline-кнопки, независимые каналы, повторные callback и возврат. Telegram-клиент может скрывать клавиатуру, /menu восстанавливает её. |
| Этапы обработки | Сбор, фильтрация, локальный текст / перевод, изображения, публикация и диагностика разделены. Простые операции не используют ИИ. |
| ИИ-провайдеры | Восемь адаптеров, ключи Secret Manager, модели и резервные модели, отключение, тест, ограничения попыток. Реальная доступность каждой модели проверяется с ключом владельца. |
| Экономия | off/free/paid, украинский оригинал без перевода, кеш, локальные картинки, квоты запросов. Жёсткий денежный потолок платных API не реализован: нужны ограничения на стороне провайдера. Неизвестная стоимость не представляется нулевой. |
| Изображения | Оригинал при разрешении, локальный Pillow-шаблон, опциональный ИИ и резерв. Авторские разрешения всех источников автоматически установить нельзя. |
| Оформление | Заголовок, факты, известные поля события, ссылки, хештеги и подпись канала. Настраиваемые текстовые шаблоны заголовка и тела, стиль и подпись; исполняемые выражения запрещены. Свободного визуального конструктора нет. |
| Уникальность | Канонический URL, исходные ID, сходство при сборе, точные заголовки/исходный текст в транзакционном индексе, миграция старой истории, независимость каналов. Автоматическое объединение фактов разных статей не выполняется. |
| Источники | Каталог 46 записей: 27 новостных RSS, 15 автоматических событийных, 4 ручных ориентира. Предыдущее тестирование RSS описано в SOURCES-RU. Повторная проверка в вашем облаке — кнопка проверки источника. |
| Внешние ограничения | Ticketmaster требует ключа и отдельного адаптера; закрытые Facebook Events не подключены. MyHelsinki не имеет отдельного адаптера в этой версии; используется городской Linked Events. Достоверные первоисточники всех публикаций конкурента не установлены. |
| Почему не публикует | Сохраняются причины пропусков. В вашем журнале подтверждены ограничения интервала/модерации/проверки ИИ, старые ошибки и большой backlog. Точная причина каждого исторического ValueError неизвестна. |
| Неопубликованное | Просмотр, редактирование, фото, повтор обработки, назначение канала, публикация с подтверждением, отклонение, расписание. Материалы сохраняются. |
| Массовая отправка | До 100 готовых карточек, выбор назначения, предупреждения, подтверждение, постоянные задания, статус, отмена. Произвольная ручная группа до 10. |
| Каналы | Добавление, архивирование с подтверждением, независимые фильтры/источники/язык/режим/изображения/лимиты; восстановление. |
| Очередь | Firestore, ограниченные повторы, восстановление запусков, блокировки отправки. Неопределённый исход Telegram требует ручной сверки: автоматическая exactly-once гарантия между двумя независимыми API невозможна. |
| Диагностика | Причины, состояния, ошибки, дедупликация уведомлений, отдельный watchdog. Полный отказ GCP требует внешнего монитора, которого в пакете нет. |
| Резерв | Настройки, источники и конфигурация сервиса; откат трафика. Добавлен ручной прикладной JSONL-экспорт истории backup-history.py; это не атомарный управляемый снимок БД и не автоматическое восстановление. История остаётся в текущей БД. |
| Тестирование | 153 автоматических локальных теста с подменёнными Telegram/Firestore; нет случайных массовых публикаций. Реальные права, квоты и доставки требуют проверки после установки. |
| Развёртывание | Полный ZIP без Git, кандидат без трафика, self-test без ИИ, переключение, диагностика и команда отката. Новая версия пока не развёрнута нами. |
| Без ИИ с нуля | Собственный текст/фото, оригинал источника, локальный шаблон и ручная публикация без API-ключей. Перевод иностранного текста без переводчика не имитируется. |

Ограничения выше оставлены явно: это не заявление, что абсолютно все пункты большого задания завершены. Не включены обходы доступа, непроверенные бесплатные тарифы или фиктивно работающие интеграции.
