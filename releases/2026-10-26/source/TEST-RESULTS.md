# Результаты проверки новой версии — 25 октября 2026

153 теста пройдены, unittest: OK, 1.778 секунды. Проверка синтаксиса Python и bash выполнена.

Дополнительные сценарии: блокировка платных запросов без ложного таймаута; Cloudflare без Account ID; сообщения без секретов; конкурирующие публикации разных URL с одним заголовком; отдельные каналы/даты; неопределённая отправка и ручная сверка; миграция старой истории в индекс повторов; отдельный обработчик только подтверждённых заданий; блокировка при занятом сборщике; быстрый профиль только после подтверждения; приоритет без обхода фильтров; безопасные текстовые шаблоны; запрет прошедших событий даже в новостном канале.

Ранее проверенные сценарии массовой очереди и работы без ИИ также проходят. Реальные Telegram/Firestore и платные модели в тестах не вызываются. Новая версия не развёрнута из этой среды; после установки требуется сверить версию, четыре Scheduler-задания и одну реальную публикацию в каждом канале. Полный экспорт истории подготовлен как отдельный ручной инструмент; на рабочей базе здесь не запускался.
