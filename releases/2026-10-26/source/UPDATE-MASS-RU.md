## Новые изменения

- Постоянная кнопка «📣 Массовая публикация», команда /mass.
- Выбор 10 / 25 / 50 / 100 свежих подготовленных материалов выбранного канала и канала назначения.
- Список заголовков, предупреждения, просмотр каждой карточки. Просмотр не меняет подтверждённый снимок материала.
- Одноразовое подтверждение атомарно создаёт задания Firestore. До подтверждения публикаций нет.
- По 3 задания за запуск сборщика; таймер продолжает обработку после закрытия Telegram. Это постепенная отправка, не 100 сообщений мгновенно. При интервале 15 минут 100 материалов потребуют около 8,5 часа; кнопка «Собрать» запускает вне очередного интервала.
- Статус групп и отмена ещё не начатых отправок. Отменённые карточки снова pending. Уже опубликованные посты остаются в канале.
- Права администратора и изменения карточек проверяются повторно. Изменение настроек после подтверждения блокирует массовое задание, чтобы не использовать устаревшие разрешения или формат.
- Просроченные/отменённые события исключаются. Неопределённый результат Telegram не повторяется вслепую: нужна сверка канала.
- Подготовка отделена от публикации: настройка «Обработать за сбор» 1–50, по умолчанию 10; «Публикаций за сбор» сохраняет прежнее назначение. Действуют общий таймаут и лимиты ИИ, поэтому 50 — верхний предел, а не гарантия.
- Режим off не требует старого одобрения проверяющего ИИ. Диагностика объясняет отсутствие разрешённых моделей и показывает задания публикации.
- Диагностический скрипт проверяет отдельный watchdog; watchdog сообщает ошибку последнего запуска, даже если его время свежее.

## Установка без Git

Загрузите finland-news-bot-v2-mass-20261025.zip через меню Upload в Cloud Shell. Можно загрузить в домашнюю папку или ~/projects/bot. Выполните целиком:

```bash
(
set -e
ARCHIVE="$HOME/finland-news-bot-v2-mass-20261025.zip"
if [ ! -f "$ARCHIVE" ]; then
  ARCHIVE="$HOME/projects/bot/finland-news-bot-v2-mass-20261025.zip"
fi
if [ ! -f "$ARCHIVE" ]; then
  echo 'Сначала загрузите finland-news-bot-v2-mass-20261025.zip в Cloud Shell.'
  exit 1
fi
UPDATE_DIR=$(mktemp -d "$HOME/finland-bot-update-XXXXXXXX")
unzip -q "$ARCHIVE" -d "$UPDATE_DIR"
cd "$UPDATE_DIR/finland-news-bot-v2"
PROJECT_ID=winged-ratio-377512 \
REGION=europe-north1 \
EVENTS_CHANNEL_ID=@eventhsl \
bash scripts/upgrade-all.sh
bash scripts/diagnose.sh
)
```

Скрипт сохраняет резерв настроек/ревизии, разворачивает кандидата без трафика, проверяет health и создание локального изображения, затем переключает трафик. Он не отправляет проверочные публикации в ваши каналы. История не выгружается в резерв настроек и не удаляется.

## Первые действия в Telegram

1. /start → Новости → «Без ИИ». Повторить для Событий, если оба канала должны работать без API. Это сохранит оригинальный язык; автоматического бесплатного качественного перевода без какого-либо переводчика не обещаем.
2. Настройки → Расписание: проверьте лимиты. Для ускоренной подготовки без ИИ можно установить «Обработать за сбор» 20. Автопубликация и фильтры остаются вашими.
3. «Собрать» → диагностика. Неподготовленные карточки не входят в массовую отправку; для старых ошибок используйте «Обслуживание → Повторить ошибки».
4. «Массовая публикация» → 10 → канал → прочитать список и предупреждения → просмотреть карточки → подтвердить.
5. «Статус / отмена заданий» показывает ожидание, успешные и неуспешные отправки. Для досрочного запуска нажмите «Собрать» в канале назначения.
6. Для произвольного набора используйте «Неопубликованные → карточка → В группу» (до 10). Для собственной публикации с нуля — «Создать пост»; ни один API-ключ не обязателен.

Массовое ручное подтверждение осознанно обходит автоматические интервалы, дневной лимит постов и модерацию. Список не отправляется автоматически лишь от его открытия. Содержимое каждой отправки должно быть проверено администратором.

## Проверка после обновления

Сначала проверьте по одному собственному посту в каждом канале. После этого подтвердите небольшую группу, дождитесь статуса published, сверьте сообщения, изображения и подписи. Повторное нажатие подтверждения не должно создавать дубли. Отмените другую ожидающую группу и проверьте возврат карточек в pending.

Откат: используйте rollback.sh, путь к которому напечатает обновление. Для показанной в журнале предыдущей рабочей ревизии:

```bash
gcloud run services update-traffic finland-news-bot \
  --project=winged-ratio-377512 --region=europe-north1 \
  --to-revisions=finland-news-bot-00007-sin=100
```

Перед откатом отмените ожидающие массовые задания в Telegram: откат кода не отменяет сохранённые задания и не удаляет уже опубликованные сообщения. Все записи совместимы с существующим scheduled_posts.
