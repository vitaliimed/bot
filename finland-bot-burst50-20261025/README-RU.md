## Быстрый запуск (Cloud Shell)

Загрузить файл `finland-bot-burst50-20261025.zip` через Cloud Shell Upload в `$HOME/projects/bot`.

```bash
cd "$HOME/projects/bot"
unzip -q -o finland-bot-burst50-20261025.zip
bash finland-bot-burst50-20261025/scripts/install-and-deploy.sh
```

Первая команда только **подготавливает** копию исходников и проводит проверки: трафик, Google Cloud Scheduler, Firestore и Telegram не изменяются. Готовый текст `CHECK COMPLETE. NO DEPLOYMENT` означает, что можно выполнить:

```bash
bash "$HOME/projects/bot/finland-bot-burst50-20261025/scripts/install-and-deploy.sh" --deploy
```

Установщик также может остановиться по отсутствию подтверждённого Cloud Build source, отсутствию Secret Manager permissions, несовместимости или неправильным тегам. Это нормальная защита, НЕ повод удалять проверки. Если STOP, прислать текст ошибки.

## Функции

### Качество постов

1. Заголовок и текст по-украински, строгая проверка языка непосредственно перед отправкой.
2. Редактор использует Gemini, Haimaker в бесплатной промоакции, затем Cloudflare text (строгая проверка; если вернулся финский текст, он отвергается).
3. Отправка с изображением: источник, если доступен → Cloudflare FLUX Schnell с лимитом не более 10 обращений/сутки → локальный шаблон.
4. Исходные цифры/даты должны сохраниться после перевода, иначе перевод отвергается.
5. Новости старше 24 часов блокируются в обычном потоке этой надстройки; в пиковом режиме старше 6 часов не рассматриваются. События с неподтверждённой или уже прошедшей датой не публикуются.
6. Указание на картинке `AI` / credits остаётся в существующем Telegram formatter.

### Команды в Telegram-боте

- `/ai_ext` — состояние нового маршрутизатора ИИ без раскрытия ключей.
- `/burst50 status` — состояние пика и последний запуск.
- `/burst50 start` — отправить до 50 актуальных уникальных новостей в пределах 30 минут.
- `/burst50 stop` — остановить текущую кампанию.
- `/burst50 auto on` — автоматически запускать пик при ≥60 подходящих уникальных новостях за период не старше 6 часов. Повторный автоматический пик не чаще одного раза в 6 часов.
- `/burst50 auto off` — выключить авто-режим; текущая кампания, если запущена, не прервётся. Для остановки — `/burst50 stop`.

Бот в пиковом режиме отправляет **максимум пять постов в минуту**. При достаточной очереди 50 публикаций займут ~10–20 минут. Не гарантируется публикация 50 записей, если свежих качественных статей недостаточно. Все публикации используют существующий атомарный `publish`/состояние `sending`, а не прямой необработанный Telegram массовый API. Попадание только в `@suominewsua`, события в этот поток не допускаются.

**Безопасное значение по умолчанию:** пиковая публикация и её авто-запуск выключены. Настройки обычной авто-публикации и лимиты старой системы не меняются.

### Выбор свежих материалов

- Подтверждённая `source_published_at` и возраст не старше шести часов. Время сбора `created_at` никогда не подставляется вместо даты публикации источника.
- Исключаются мероприятия, просроченные, отменённые, чувствительные, с отсутствующими данными и слишком общими заголовками.
- Дедупликация по нормализованному URL и близости заголовка; учитываются часть ранее опубликованных материалов из Firestore. Встроенная защита `story_uniqueness` исходного бота сохраняется.
- Приоритет: возраст, уровень важности, полнота текста и категория.

## Лимиты расходов

- Gemini: прямой API-тест уже подтвердил перевод. Приложение не может гарантировать бесплатную квоту; контролируйте расход Gemini отдельно.
- Haimaker: **строго запрещены автоматические вызовы после 1 ноября 2026 14:00 UTC** (если пользователь явно не установил `BOT_HAIMAKER_ALLOW_PAID=1`). Текущее правило по умолчанию защищает $20 остатка.
- Cloudflare: FLUX подтверждён реальным тестом. По умолчанию 10 генераций/сутки, затем шаблоны. На платном тарифе Workers AI расход может тарифицироваться и при меньшем числе генераций в зависимости от модели/аккаунта.
- Внешних переводов по новой надстройке до 120/сутки (общее количество материалов, а не API вызовов; до трёх последовательных провайдеров на материал).
- Не используем OpenAI, DeepSeek в собственном маршрутизаторе надстройки. Старые настройки других путей приложения не меняются без необходимости.

## Секреты и инфраструктура

Используются только Google Secret Manager:
- `finland-bot-haimaker-api-key` — существующий секрет с подтверждённым тестом Haimaker.
- `finland-bot-cloudflare-workers-token` — создаётся из предыдущего проверенного Cloudflare API ключа, ранее сохранённого в секрете/Firestore.
- Исполняющий service account получает права `secretAccessor` **только** на эти два секрета.

`BOT_CF_ACCOUNT_ID` — публичный технический идентификатор аккаунта Cloudflare (не API-токен).

Создаётся Cloud Scheduler HTTP job `finland-news-burst50` раз в минуту в `europe-west1`, с OIDC авторизацией. Он не начнёт публиковать, пока администратор не включит пиковый режим. Нет обхода webhook, OIDC, роли администратора.

## Откат

Скрипт записывает сведения о предыдущем трафике и команду отката в `~/bot-burst-backups/peak50-*/ROLLBACK.txt`. Для подтверждённой текущей ревизии до установки:

```bash
gcloud run services update-traffic finland-news-bot --project winged-ratio-377512 \
  --region europe-north1 --to-revisions finland-news-bot-00010-cec=100
```

Если установка остановилась до переключения, откат не нужен. Состояния нового Burst 50 сохраняются в Firestore; откат к старому коду не удаляет историю постов.
