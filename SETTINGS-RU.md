# Настройки публикации

Откройте `/settings` в личном чате с ботом. Доступ сохраняется у владельца и администраторов канала с правом публикации, если выбран режим `channel_admins`. Настройки сохраняются в Firestore и переживают обновления сервиса.

В меню есть переключатели автопубликации, каждой темы, режима картинок и проверяющего ИИ. В `/sources` — кнопки включения/отключения источников. Любой параметр меняется командой `/set ИМЯ значение`; `/reset ИМЯ` возвращает его значение по умолчанию. Изменение настроек не переписывает уже опубликованные посты.

## Изображения

По умолчанию: изображение из RSS (media/enclosure/img), затем Open Graph/Twitter Image со страницы статьи. При отсутствии подходящего изображения — генерация: OpenAI, затем Gemini, если соответствующий ключ подключён. Недоступные провайдеры пропускаются. Сетевые ошибки/отказы провайдера допускают переход к следующему в пределах времени обработки и дневного лимита.

Пост отправляется одним `sendPhoto` с подписью; для длинной новости текст сокращается до лимита подписи Telegram (1024 единицы UTF-16). Подпись содержит источник, а генерация — обязательную отметку «Ілюстрація ШІ». Создаётся тематическая рисованная иллюстрация; она не выдаётся за документальный снимок события.

Фото источника можно использовать только с необходимым разрешением. Автоматической проверки лицензий нет. `/sourceimages ID off` запрещает брать фотографии этого источника для новых материалов; при включённой генерации вместо них используется иллюстрация. При изменении правила уже подготовленные изображения сохраняются.

| Параметр | По умолчанию | Варианты |
|---|---|---|
| image_mode | source_generate | off — без фото; source — только источник; source_generate — источник, затем генерация; generate — только генерация |
| image_order | openai,gemini | Порядок генераторов; можно оставить один |
| image_daily_limit | 3 | 0–30 попыток API в день; ошибочные/неясные ответы тоже учитываются |
| require_image | off | on — без фото материал остаётся в очереди; off — возможен текстовый пост |
| openai_image_model | gpt-image-2.5-flare | Доступная вашему API-аккаунту GPT Image модель |
| image_quality | low | low, medium, high для OpenAI |
| image_model | gemini-3.1-flash-image | Доступная Gemini модель генерации изображений |

Примеры команд боту:

```text
/set image_order openai,gemini
/set image_daily_limit 2
/set require_image on
```

Генерация изображений оплачивается по тарифу API-провайдера; лимит попыток не является денежным лимитом аккаунта. Одна новость может использовать две попытки, если первый генератор вернул ошибку. Для отключения всех платных генераций: `/set image_daily_limit 0` или `/set image_mode source`.

В `/queue` кнопка «Превью» отправляет подготовленный пост только в ваш личный чат. Если картинки ещё нет, превью пробует её подготовить и расходует тот же дневной лимит. Заготовленные изображения хранятся в Firestore в JPEG до 450 КБ, после публикации заменяются Telegram file_id. Подготовленные до обновления материалы получают изображение через «Превью»; автоматическая переделка всей старой очереди не выполняется.

## Дополнительные ИИ

В Cloud Shell подключите ключ нужного провайдера:

```bash
cd "$HOME/projects/bot"
bash scripts/connect-ai.sh openai
# При необходимости отдельный резервный провайдер:
bash scripts/connect-ai.sh groq
```

Скрипт попросит API-ключ без отображения и сохранит его в Secret Manager. Ключ OpenAI используется и для текста, и для изображений. Запросы с API-ключом оплачиваются отдельно от подписки ChatGPT. Наличие ключа не гарантирует доступ к конкретной модели/квоте; выберите доступные модели в настройках. `/settings` показывает наличие ключей, а не успешность оплаты или проверку API.

| Параметр | По умолчанию | Назначение |
|---|---|---|
| ai_order | gemini,groq,openai | Первый настроенный редактор; при ошибке/невалидном JSON — следующий |
| review_provider | off | off, gemini, groq, openai — дополнительная проверка черновика |
| gemini_model | GEMINI_MODEL / gemini-3.5-flash-lite | Текстовая Gemini модель |
| groq_model | openai/gpt-oss-20b | Текстовая модель Groq |
| openai_model | gpt-4.1-mini | Текстовая OpenAI модель |

Например, `/set review_provider groq` включает проверяющего. Без успешного одобрения этого провайдера автоматической публикации не будет. Проверка сопоставляет черновик с фактами RSS, а не подтверждает событие по независимым источникам. Законодательство, Migri, Kela, медицина, безопасность и неполные анонсы требуют ручной модерации независимо от одобрения ИИ.

После подключения нового проверяющего старые черновики можно отправить на повторную обработку: `/retry ID`. ID указан в `/queue`. `/failed` показывает ошибки; автоматических повторов подготовки не больше трёх. Ручное редактирование снимает одобрение ИИ и требует ручной публикации.

## Расписание, отбор и оформление

| Параметр | По умолчанию | Допустимые значения |
|---|---|---|
| categories | Все темы | news,ukraine,sport,children,events,transport,other; кнопки в меню |
| daily_limit | 12 | 0–100 автоматических постов в день |
| interval_minutes | 60 | 0–1440 минут между публикациями |
| window_start / window_end | 08:00 / 22:00 | HH:MM; одинаковое время — круглосуточно; поддерживается окно через полночь |
| timezone | Europe/Helsinki | Зона IANA; переход на летнее время учитывается |
| weekdays | 1,2,3,4,5,6,7 | 1 — понедельник, 7 — воскресенье |
| max_age_hours | 48 | 1–720; дата источника, если она доступна, иначе дата сбора |
| include_words | Пусто | Через запятую; достаточно одного совпадения в заголовке/тексте |
| exclude_words | Пусто | Через запятую; любое совпадение исключает материал |
| batch_size | 3 | 1–10 материалов на запуск, дополнительно ограничено временем |
| body_length | 650 | 150–2500 символов; подпись к фото имеет отдельный лимит |
| language | українська | українська, русский, English |
| tone | нейтральний | нейтральний, коротко, дружній |
| hashtags / source_link | on / on | on, off |
| signature | Пусто | До 150 символов; `-` очищает |
| silent | off | on — публикация без уведомления |

Пример для канала с новостями без спорта:

```text
/set categories news,ukraine,children,events,transport,other
/set daily_limit 8
/set interval_minutes 90
/set window_start 09:00
/set window_end 21:00
```

Для очистки фильтра: `/set exclude_words -`. Список тем можно менять кнопками без команды. Спорт по умолчанию сохраняется включённым, как в предыдущей версии; лента Yle Sport управляется отдельно в `/sources`.

Cloud Scheduler запускается каждые 30 минут: время и интервал — ограничения, а не обещание отправки в точную минуту. Настройки применяются также к старой очереди; выключенный/удалённый источник не публикуется автоматически. При включении авто ранее подготовленные подходящие материалы постепенно выходят по расписанию.

Кнопка «Опубликовать» — ручное решение: обходит фильтры тем, расписание, дневной лимит и проверки ИИ. Требование наличия изображения сохраняется. Ручные посты тоже учитываются в дневном счётчике и интервале для следующих автоматических постов. При неясном результате отправки статус `needs_reconciliation` блокирует повтор: сначала проверьте канал, поскольку Telegram мог уже принять пост.

## Проверка разработки

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
```

Проверки используют имитацию API и Firestore, не публикуют тестовые посты в канал и не расходуют платную генерацию. Реальные ключи, квоты и доступ к моделям проверяются после подключения в вашем Cloud Run.
